# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript**. Control the snake using keyboard arrow keys, eat food to grow longer, and try to achieve the highest score without hitting the walls or yourself!

## 🎮 Features

- **Keyboard Controls:** Move the snake using the arrow keys.
- **Food System:** Food appears randomly on the game board.
- **Snake Growth:** The snake grows whenever it eats food.
- **Score Tracking:** Score increases with every food item collected.
- **Collision Detection:** Detects collisions with walls and the snake's own body.
- **Game Over:** The game ends when the snake hits a wall or itself.
- **Simple UI:** Clean and minimal game interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic, movement, and collision detection.
- **HTML5 Canvas** – Rendering the snake and food.
